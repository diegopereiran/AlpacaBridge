# LeakSanitizer suppressions for the nightly all-vendors ASan job and the
# sanitizer run in scripts/ci_preflight.sh (issue #1796).
#
# ONLY libgphoto2 frames belong here. gp_camera_autodetect() (called from
# GPhotoSDKWrapper::enumerate_cameras(), which frees its own CameraList)
# reaches libgphoto2_port/libusb1/libusb1.c, which keeps the result of
# libusb_get_device_list() in port->pl->devs (line 212) and frees it only
# `if (nrofdevs)` (lines 190-193 and 432-436) -- libgphoto2 2.5.34, the
# tarball scripts/build_bundled_gphoto.sh builds. libusb allocates that array
# even when it lists no device, so a host with no USB device leaks it on every
# autodetect. We cannot fix libgphoto2 here; a leak reached from our own code
# must never be suppressed -- fix the code instead.
#
# `leak:` matches any frame of the allocation stack, so this hides only leaks
# whose stack passes through gp_port_usb_find_device.
leak:gp_port_usb_find_device
