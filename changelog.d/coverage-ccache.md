### Changed (CI)
- **The coverage job's compiler cache works** (CI): ccache 4.9 rejects `-fprofile-update=atomic` as an unknown profiling option and cached none of the coverage job's compiles (4888 of 4888 uncacheable, run 39102485820), so every run compiled from scratch (about 244 s). The option now comes from a small compiler wrapper ccache does not see, with `CCACHE_COMPILERCHECK=content` so the cache key follows the wrapper and the real compiler version it records. The report step runs gcov once instead of three times: the combined report writes gcovr's JSON, and the AlpacaCore and AlpacaHTTP reports are filtered from it. Manual runs now save the cache too, so a branch can be measured warm.
