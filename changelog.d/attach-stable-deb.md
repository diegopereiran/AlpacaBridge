### Changed (tooling)
- **Stable Releases carry the arm64 `.deb` too** (release process, `.github/workflows/release.yml`, `docs/beta-channel.md`, `docs/development.md`, `/bump-release`; the `stable/5.0` port of #1338): the `beta-deb` job is renamed `deb` and now runs for every tag, stable `vX.Y.Z` and beta `vX.Y.Z-beta.N`, and for every dry run, which builds and uploads nothing. It attaches `alpacabridge_<tag without v>_arm64.deb` (for example `alpacabridge_5.0.0_arm64.deb`) and the `alpacabridge-dbgsym_<tag without v>_arm64.deb` debug-symbols package, each with a `.sha256` that holds the `sha256sum` line for that file name, so the apt repository can re-host the stable package from the Release instead of building it elsewhere; the build fails if `dpkg-buildpackage` did not produce the dbgsym package. The `.deb` keeps its provenance attestation, now on stable tags too, and the dbgsym package is a second subject of it. Beta asset names do not change.
