### Added (tooling)
- **Beta channel release tooling** (release process, `release.yml`, `scripts/release_tag.py`, `scripts/changelog_fragments.py`, `scripts/check_docs_drift.py`, `docs/beta-channel.md`): a tag `vX.Y.Z-beta.N` now publishes a GitHub pre-release from `docs/releases/X.Y.Z-beta.N.md` with no dated CHANGELOG section, after mapping the tag to the `X.Y.Z~betaN` VERSION spelling (`release_tag.py --self-test` covers the mapping and the Debian order). `changelog_fragments.py` accepts a `~betaN` VERSION (`--bump --version`, `--release`, `--preview --version`), docs-drift check 4 accepts a beta README badge, CI and CodeQL also run on pushes to `stable/**`, and `/bump-release`, `/submit-pr` and `/pr-checker` gain beta, stable-branch and merge-down modes. AlpacaCore and AlpacaHTTP CMake pass `project()` only the numeric part of `VERSION`, so a `~betaN` VERSION configures, and keep the full string in `ALPACACORE_VERSION` and `ALPACAHTTP_VERSION`. No user-visible change until a beta is cut.
