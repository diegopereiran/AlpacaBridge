### Changed (CI)
- **Pull requests no longer build the `.deb`** (CI): the `package-deb` job leaves `ci.yml`, where it built, installed and checked the package on every pull request (about 4.5 minutes each, docs-only PRs included). The nightly build (`.github/workflows/nightly-build.yml`) now installs the `.deb` it builds and runs `scripts/check_bundled_gphoto.sh` before it publishes, so a broken bundle is never published; `release.yml` still builds the `.deb` for every stable and beta tag. A packaging break now shows in the next nightly run instead of on the pull request. Decision 0012's Rules, the gphoto instructions and the CI-gates instructions name the new owner.
