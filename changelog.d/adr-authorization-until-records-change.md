### Changed (tooling)
- **One decision-record authorization lasts until the records change** (`scripts/check_adr_authorization.py`, `.github/workflows/decision-records.yml`, `docs/decisions/README.md`, PR template, ci-gates instructions): `ADR authorized <sha>` used to hold only while `<sha>` was the PR head, so every push, even a code-only review fix, needed a new comment. It now holds for a later head as long as every decision-record file the PR changes has the same content there as at `<sha>`, compared by git blob, so a merge of the base branch or a rebase that leaves the records alone keeps it. A push that edits, adds or removes one of those records still needs a new authorization, and a commit GitHub cannot resolve does not count.
